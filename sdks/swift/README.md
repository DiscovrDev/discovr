# Swift6 API client for Discovr

The Discovr API powers personalized recommendation experiences for your streaming app.

**Authentication.** Two tokens, two jobs:

- **Refresh token** (long-lived, 90 days). Used for identity-tier
  endpoints — managing profiles, signing out the current device, and
  starting browsing sessions. Treat it as a credential.
- **Session token** (short-lived, 30 minutes). Scoped to a selected
  profile. Used for session-tier endpoints — pages, rows, items, and
  writes to profile-scoped data.

Sign in via the web flow or the device-code flow → receive a refresh
token → call `POST /auth/session-token` with a chosen `profileId` → use
the returned session token for everything else. SDKs handle this
transparently; see the
[Authentication guide](https://docs.discovr.media/guides/authentication).

**Profiles.** A user can have multiple profiles, each with independent
likes, history, playback, and watchlists. The active profile is carried
by the session token, so profile-scoped endpoints don't accept a
`profileId` path parameter — they live under `/profile/_*`.
