# Discovr documentation

The source for [docs.discovr.media](https://docs.discovr.media), built with [Mintlify](https://mintlify.com/).

## What's in here

- **`guides/`**: the developer guides, from your first sign-in to a full browse experience.
- **`api-reference/`** and **`sdk-reference/`**: one page per operation and per SDK method. Generated from the API spec, so they're not edited by hand.
- **`openapi.yaml`**: the bundled API specification. Also generated.
- **`docs.json`**: site configuration and navigation.
- **`assets/`**: logos and the screenshots the guides use.

## Preview locally

From this directory:

```bash
npx mintlify dev
```
