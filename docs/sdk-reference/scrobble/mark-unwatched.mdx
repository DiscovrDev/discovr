---
title: "markUnwatched()"
description: "Mark a title as unwatched"
---

Takes a movie, a TV show, a season, or an episode back to unwatched, in one call.

It removes the history that made it watched, takes it out of the user's **in-progress** list if that is where it was, and brings a TV show's `completed` state back in line. Use it for a "Mark as unwatched" button.

For TV shows, `season` and `episode` choose how much to undo:

- Omit both to undo **the whole show**, every season.
- Pass `season` to undo **that season**: its episodes, and any entry that counted the whole season as watched.
- Pass `season` and `episode` to undo **that episode**.

Calling it for a title that isn't watched changes nothing and still succeeds, so it is safe to retry.

This is not the same as [`DELETE /profile/history/&#123;mediaId&#125;`](/api-reference/discovr/delete-history-item), which removes history entries and nothing else. Marking something unwatched with that call and `DELETE /profile/playback/&#123;mediaId&#125;` leaves a TV show's `completed` out of date unless they run in a particular order; this endpoint does the right thing whichever way you reach it.

**Auth tier:** session — send your session token in `Authorization: Bearer`.

## Parameters

| Name    | Type      | Required | Description                                                                                                                                     |
| ------- | --------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| mediaId | `string`  | Yes      | The media ID in `MV_&lt;number&gt;` or `TV_&lt;number&gt;` format (e.g., `MV_550`, `TV_1396`). Also accepts an item's `ref` in place of the id. |
| season  | `integer` | No       | TV only. Season number. Omit to undo every season of the show.                                                                                  |
| episode | `integer` | No       | TV only, and only together with `season`. Episode number. Omit to undo the whole season.                                                        |

## Returns

[`SuccessMessage`](/sdk-reference/types/common#successmessage) — The title is unwatched.

## Example

<CodeGroup>

```typescript TypeScript
import { DiscovrClient } from "discovr";
import type { SuccessMessage } from "discovr";

const discovr = new DiscovrClient("your-client-id");

// After sign-in and profile selection …
const response: SuccessMessage = await discovr.markUnwatched("TV_1396", { season: 1, episode: 5 });
console.log(response);
```
