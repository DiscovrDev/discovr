---
title: "scrobbleSkip()"
description: "Record a skip event"
---

Signals that the user jumped to another point in the content, forward (a skip) or backward (a rewind). Used for watch analytics. Returns immediately — no side effects on lists or history.

`from` and `to` are playback positions as a percentage (0–100) and must differ; `from` higher than `to` is a jump backward. `duration` is how many seconds were jumped. After a jump, also send the position the viewer landed on as a progress update with `POST /profile/scrobble/&#123;mediaId&#125;`.

## Parameters

| Name     | Type                                                     | Required | Description                                                                                                                                                                                                                                                 |
| -------- | -------------------------------------------------------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| mediaId  | `string`                                                 | Yes      | The media ID in `MV_&lt;number&gt;` or `TV_&lt;number&gt;` format (e.g., `MV_550`, `TV_1396`). Also accepts an item's `ref` in place of the id. Prefer the `ref` when you have one — it resolves to the same title and sharpens the user's recommendations. |
| from     | `number`                                                 | Yes      | Playback position where the skip started (0–100).                                                                                                                                                                                                           |
| to       | `number`                                                 | Yes      | Playback position where the skip landed (0–100).                                                                                                                                                                                                            |
| duration | `number`                                                 | Yes      | Number of seconds skipped.                                                                                                                                                                                                                                  |
| tv       | [`ScrobbleTv`](/sdk-reference/types/scrobble#scrobbletv) | No       | Which episode is playing. Required for TV shows, omitted for movies.                                                                                                                                                                                        |

## Example

<CodeGroup>

```typescript TypeScript
import { DiscovrClient } from "discovr";
import type { ScrobbleSkipBody, ScrobbleSkipResponse, ScrobbleTv } from "discovr";

const discovr = new DiscovrClient("your-client-id");

// After sign-in and profile selection …
const response: ScrobbleSkipResponse = await discovr.scrobbleSkip("TV_1396", 10, 20, 20, {
	tv: { season: 2, episode: 5 },
});
console.log(response);
```

```kotlin Kotlin

}
```
