---
title: "markWatched()"
description: "Mark a title, season, or episode as watched"
---

Marks a movie, an entire TV show, a season, or a single episode as watched in one atomic call.

For TV shows, `season` and `episode` pick the scope:

- Omit both to mark **every aired episode** across all regular seasons (season 1 and up) as watched. Specials (season `0`) are excluded.
- Pass `season` to mark every aired episode of **that season**.
- Pass `season` and `episode` to mark **that episode**.

Any in-progress Continue Watching position within the marked scope is cleared automatically. Returns the title's updated `TitleState`, so you don't need to refetch `getTitleState`.

**Auth tier:** session — send your session token in `Authorization: Bearer`.

## Parameters

| Name    | Type      | Required | Description                                                                              |
| ------- | --------- | -------- | ---------------------------------------------------------------------------------------- |
| mediaId | `string`  | Yes      | The title's media ID (`MV_&lt;id&gt;` or `TV_&lt;id&gt;`), or an item `ref`.             |
| season  | `integer` | No       | TV only. Season number. Omit to mark every aired season of the show.                     |
| episode | `integer` | No       | TV only, and only together with `season`. Episode number. Omit to mark the whole season. |

## Returns

[`TitleState`](/sdk-reference/types/common#titlestate) — Marked as watched; returns the title's new state.

## Example

<CodeGroup>

```typescript TypeScript
import { DiscovrClient } from "discovr";
import type { TitleState } from "discovr";

const discovr = new DiscovrClient("your-client-id");

// After sign-in and profile selection …
const response: TitleState = await discovr.markWatched("TV_1396", { season: 1, episode: 5 });
console.log(response);
```

```kotlin Kotlin
import api.discovr.DiscovrClient
import api.discovr.models.TitleState

// Construct DiscovrClient with your AuthStorage implementation (see SDK README).
suspend fun example(client: DiscovrClient) {
    val response: TitleState = client.markWatched(mediaId = "TV_1396", season = 1, episode = 5)
    println(response)
}
```
