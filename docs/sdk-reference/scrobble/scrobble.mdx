---
title: "scrobble()"
description: "Record playback progress"
---

Scrobbling is Discovr's single-call way to track playback. One call updates live resume progress, watch history, completion, and the watchlist.

Send the viewer's real position when playback starts (not `0` when resuming), about every 30 seconds while watching, and right away on pause, resume, seek, and completion. Discovr handles the rest:

- The title stays in Continue Watching until the movie or episode crosses 80%.
- Once progress reaches 20% or more, the title is automatically removed from the watchlist — for both movies and TV shows.
- Once progress reaches 80% or more, the movie or episode is marked watched and leaves Continue Watching. Lower progress later (such as a rewind) moves the live position without undoing completion — use `markUnwatched` to undo a watch.
- For TV shows, include `season` and `episode` in `tv`. When an episode crosses 80%, the response includes `completedSeasons` listing every season now fully watched.

**Auth tier:** session — send your session token in `Authorization: Bearer`.

## Parameters

| Name     | Type                                                     | Required | Description                                                                                                                                                                                                                                                 |
| -------- | -------------------------------------------------------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| mediaId  | `string`                                                 | Yes      | The media ID in `MV_&lt;number&gt;` or `TV_&lt;number&gt;` format (e.g., `MV_550`, `TV_1396`). Also accepts an item's `ref` in place of the id. Prefer the `ref` when you have one — it resolves to the same title and sharpens the user's recommendations. |
| progress | `number`                                                 | Yes      | Current playback position as a percentage (0–100).                                                                                                                                                                                                          |
| tv       | [`EpisodeRef`](/sdk-reference/types/scrobble#episoderef) | No       | Which episode is playing. Required for TV shows, omitted for movies.                                                                                                                                                                                        |

## Returns

[`ScrobbleResponse`](/sdk-reference/types/scrobble#scrobbleresponse) — Progress recorded. Check `completed` to know if the movie or episode reached 80%.

<AccordionGroup>
<Accordion title="View response structure">
```json
{
  "status": "string",
  "progress": 85,
  "completed": false,
  "completedSeasons": ["integer"]
}
```
</Accordion>
</AccordionGroup>

## Example

<CodeGroup>

```typescript TypeScript
import { DiscovrClient } from "discovr";
import type { EpisodeRef, ScrobbleProgressBody, ScrobbleResponse } from "discovr";

const discovr = new DiscovrClient("your-client-id");

// After sign-in and profile selection …
const response: ScrobbleResponse = await discovr.scrobble("TV_1396", 42.5, {
	tv: { season: 2, episode: 5 },
});
console.log(response);
```

```kotlin Kotlin
import api.discovr.DiscovrClient
import api.discovr.models.EpisodeRef
import api.discovr.models.ScrobbleProgressBody
import api.discovr.models.ScrobbleResponse

// Construct DiscovrClient with your AuthStorage implementation (see SDK README).
suspend fun example(client: DiscovrClient) {
    val response: ScrobbleResponse = client.scrobble(mediaId = "TV_1396", progress = 42.5, tv = EpisodeRef(season = 2, episode = 5))
    println(response)
}
```

```swift Swift
import Discovr

let client = DiscovrClient(clientId: "your-client-id")
// Response / argument types:
// EpisodeRef, ScrobbleProgressBody, ScrobbleResponse

```
