---
title: "deleteProfile()"
description: "Delete a profile"
---

Permanently deletes the profile. This action can't be undone.

Deleting an account's only profile is allowed. The account then has no profiles and can't mint a session token until a new one is created — see [Handle zero profiles](/guides/profiles/listing-and-selecting-profiles). Returns 404 if the profile doesn't exist or doesn't belong to the signed-in user.

## Parameters

| Name      | Type     | Required | Description                      |
| --------- | -------- | -------- | -------------------------------- |
| profileId | `string` | Yes      | The ID of the profile to delete. |

## Returns

[`DeleteProfileResponse`](/sdk-reference/types/profiles#deleteprofileresponse) — Profile deleted.
