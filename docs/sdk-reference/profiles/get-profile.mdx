---
title: "getProfile()"
description: "Get a profile"
---

Returns a single profile by ID. Returns 404 if the profile doesn't exist or doesn't belong to the signed-in user.

## Parameters

| Name      | Type     | Required | Description                        |
| --------- | -------- | -------- | ---------------------------------- |
| profileId | `string` | Yes      | The ID of the profile to retrieve. |

## Returns

[`Profile`](/sdk-reference/types/profiles#profile) — Profile returned successfully.

```json
{
  "id": "string",
  "name": "string",
```

## Example

<CodeGroup>

```typescript TypeScript
import { DiscovrClient } from "discovr";
import type { Profile } from "discovr";

const discovr = new DiscovrClient("your-client-id");

// After sign-in …
const response: Profile = await discovr.getProfile("profile_abc123xyz");
console.log(response);
```

```kotlin Kotlin

```
