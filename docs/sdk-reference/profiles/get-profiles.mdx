---
title: "getProfiles()"
description: "List profiles"
---

Returns the signed-in user's profiles, newest first. Each one carries its
ID, display name, avatar URL, and creation timestamp.

A profile that can't be read is left out of the response rather than
failing it, so a single bad profile never costs the user their whole
picker. Treat the list as complete for display purposes, and don't assume
a missing profile means it was deleted.

**Auth tier:** identity — send your refresh token in the `Authorization: Bearer` header.

## Returns

[`GetProfilesResponse`](/sdk-reference/types/profiles#getprofilesresponse) — Profiles returned successfully

<AccordionGroup>
<Accordion title="View response structure">

```json
  "profiles": [

  "createdAt": "string" /* date-time */
}
]
}
```
