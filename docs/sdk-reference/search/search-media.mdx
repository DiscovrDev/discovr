---
title: "searchMedia()"
description: "Search media"
---

Searches across movies, TV shows, and people. Returns a ranked list of matches. Use the `query` (or `q`) parameter for the search term.

Results are ordered by relevance — preserve that order rather than re-sorting client-side.

This endpoint does not accept filters. To browse by genre, runtime, release window, or watch provider, create a page with `pageFilters` instead.

## Parameters

| Name  | Type      | Required | Description                                                                                                            |
| ----- | --------- | -------- | ---------------------------------------------------------------------------------------------------------------------- |
| query | `string`  | No       | Search term. Use `query` or `q` — if both are provided, `query` takes precedence.                                      |
| q     | `string`  | No       | Search term (shorthand for `query`). At least one of `query` or `q` is required.                                       |
| page  | `integer` | No       | Page of results to return, starting at 1. Check `has_more` on the response to decide whether to request the next page. |

## Returns

[`SearchResponse`](/sdk-reference/types/search#searchresponse) — Search results returned successfully.

## Example

<CodeGroup>

```typescript TypeScript
import { DiscovrClient } from "discovr";
import type { SearchResponse } from "discovr";

const discovr = new DiscovrClient("your-client-id");

// After sign-in and profile selection …
const response: SearchResponse = await discovr.searchMedia({
	query: "avatar",
	q: "avatar",
	page: 1,
});
console.log(response);
```

}
