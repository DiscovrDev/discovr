---
title: "getSimilarRecommendations()"
description: "Get similar titles"
---

Returns titles that are similar to the given movie or TV show. Useful for "More like this" sections.

This is a public endpoint — no authentication required. Returns only generic catalog metadata.

## Parameters

| Name     | Type      | Required | Description                                                                                                                                                                                                                                                                                       |
| -------- | --------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| mediaId  | `string`  | Yes      | The unique identifier of the media item. Use `MV_&lt;id&gt;` for movies or `TV_&lt;id&gt;` for TV shows (e.g., `MV_550`, `TV_1396`). Also accepts an item's `ref` in place of the id. Prefer the `ref` when you have one — it resolves to the same title and sharpens the user's recommendations. |
| language | `string`  | No       | Language code for results (e.g., `en-US`).                                                                                                                                                                                                                                                        |
| page     | `integer` | No       | Page number for pagination (default: 1).                                                                                                                                                                                                                                                          |

## Returns

[`SimilarResponse`](/sdk-reference/types/media#similarresponse) — Similar titles returned successfully.

## Example

<CodeGroup>

```typescript TypeScript
import { DiscovrClient } from "discovr";
import type { SimilarResponse } from "discovr";

const discovr = new DiscovrClient("your-client-id");

const response: SimilarResponse = await discovr.getSimilarRecommendations("example", {
	language: "en-US",
	page: 1,
});
console.log(response);
```
