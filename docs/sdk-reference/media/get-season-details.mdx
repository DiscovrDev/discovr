---
title: "getSeasonDetails()"
description: "Get TV season details"
---

Returns episode details for a specific TV season — episode titles, overviews, air dates, and episode numbers.

This is a public endpoint — no authentication required. Returns only generic catalog metadata.

## Parameters

| Name         | Type      | Required | Description                                                                                                                                                                                                          |
| ------------ | --------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| mediaId      | `string`  | Yes      | The unique identifier of the TV show (e.g., `TV_1396`). Also accepts an item's `ref` in place of the id. Prefer the `ref` when you have one — it resolves to the same title and sharpens the user's recommendations. |
| seasonNumber | `integer` | Yes      | The season number.                                                                                                                                                                                                   |
| language     | `string`  | No       | ISO 639-1 language code for localised results (e.g., `en`).                                                                                                                                                          |

## Returns

[`SeasonDetailsResponse`](/sdk-reference/types/media#seasondetailsresponse) — Season details returned successfully.
