---
title: "getMedia()"
description: "Get media details"
---

Returns full details for a movie or TV show — title, overview, genres, release date, runtime, cast, crew, watch providers, and more. Pass `MV_&lt;id&gt;` for movies or `TV_&lt;id&gt;` for TV shows (e.g., `MV_550`, `TV_1396`).

This is a public endpoint — no authentication required. Returns only generic catalog metadata; personalized fields live under `profile_meta`.

## Parameters

| Name    | Type     | Required | Description                                                                                                                                                                                                                                                                                       |
| ------- | -------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| mediaId | `string` | Yes      | The unique identifier of the media item. Use `MV_&lt;id&gt;` for movies or `TV_&lt;id&gt;` for TV shows (e.g., `MV_550`, `TV_1396`). Also accepts an item's `ref` in place of the id. Prefer the `ref` when you have one — it resolves to the same title and sharpens the user's recommendations. |

## Returns

[`MediaResponse`](/sdk-reference/types/media#mediaresponse) — Full media details returned successfully.
