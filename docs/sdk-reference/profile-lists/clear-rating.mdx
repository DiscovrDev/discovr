---
title: "clearRating()"
description: "Clear a title's rating"
---

Clears the active profile's rating for a title. Safe to call if the title has no rating.

Returns the title's updated `TitleState`, so you can update your UI immediately without calling `getTitleState` again.

**Auth tier:** session — send your session token in `Authorization: Bearer`.

## Parameters

| Name    | Type     | Required | Description                                                                  |
| ------- | -------- | -------- | ---------------------------------------------------------------------------- |
| mediaId | `string` | Yes      | The title's media ID (`MV_&lt;id&gt;` or `TV_&lt;id&gt;`), or an item `ref`. |

## Returns

[`TitleState`](/sdk-reference/types/common#titlestate) — Rating cleared; returns the title's new state.

## Example

<CodeGroup>

```typescript TypeScript
import { DiscovrClient } from "discovr";
import type { TitleState } from "discovr";

const discovr = new DiscovrClient("your-client-id");

// After sign-in and profile selection …
const response: TitleState = await discovr.clearRating("MV_550");
console.log(response);
```
