---
title: "getTitles()"
description: "List titles by rating, watchlist, or watch history"
---

Returns a paginated list of titles for the active profile, ordered most recent first.

Pass **exactly one** filter query parameter:

- `rating=liked`, `rating=disliked`, or `rating=super_liked` — titles with that rating, newest rated first.
- `watchlist=true` — the profile's watchlist, newest added first.
- `watched=true` — the profile's watch history (one entry per title, with `completed`, `plays`, and the last episode for TV shows), most recently watched first.

Each item includes a `ref` alongside its `id`. Pass the `ref` when the viewer opens or acts on the title.

**Auth tier:** session — send your session token in `Authorization: Bearer`.

## Parameters

| Name          | Type                                     | Required | Description                                                            |
| ------------- | ---------------------------------------- | -------- | ---------------------------------------------------------------------- |
| rating        | `"liked" \| "disliked" \| "super_liked"` | No       | Filter by rating (`liked`, `disliked`, or `super_liked`).              |
| watchlist     | `boolean`                                | No       | Set to `true` to list the profile's watchlist.                         |
| watched       | `boolean`                                | No       | Set to `true` to list the profile's watch history (one row per title). |
| nextPageToken | `string`                                 | No       | Opaque cursor token from the previous page.                            |
| limit         | `integer`                                | No       | Maximum number of titles to return (1–50, default 10).                 |

## Returns

[`TitleListResponse`](/sdk-reference/types/profile-lists#titlelistresponse) — Paginated list of matching titles.

## Example

<CodeGroup>

```typescript TypeScript
import { DiscovrClient } from "discovr";
import type { Rating, TitleListResponse } from "discovr";

const discovr = new DiscovrClient("your-client-id");

// After sign-in and profile selection …
const response: TitleListResponse = await discovr.getTitles({
	rating: "liked",
	watchlist: true,
	watched: true,
	nextPageToken: "example",
	limit: 10,
});
console.log(response);
```
