---
title: "getHistoryItemsByMediaId()"
description: "Get history items for a specific media"
---

Returns history entries for a specific title. Newest entries first.

For TV shows, pass `season` as a query parameter (required) and optionally `episode` to filter by episode. Omitting `episode` returns all entries for the whole season.

**Pagination:**
Pass `nextPageToken` from the previous response to fetch the next page. If `hasMore` is `true`, more items are available.

## Parameters

| Name          | Type      | Required | Description                                                                                                                                                                                                                                                       |
| ------------- | --------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| mediaId       | `string`  | Yes      | The media ID of the title. Format: `MV_&lt;number&gt;` for movies, `TV_&lt;number&gt;` for TV shows. Also accepts an item's `ref` in place of the id. Prefer the `ref` when you have one — it resolves to the same title and sharpens the user's recommendations. |
| season        | `integer` | No       | Season number. Required for TV shows (`TV_` mediaId); ignored for movies.                                                                                                                                                                                         |
| episode       | `integer` | No       | Episode number. Optional — omit to return all entries for the season; include to filter to a specific episode.                                                                                                                                                    |
| nextPageToken | `string`  | No       | Opaque token from previous page for pagination                                                                                                                                                                                                                    |
| limit         | `integer` | No       | Maximum number of items to return (1-50, default: 10)                                                                                                                                                                                                             |

## Returns

[`HistoryListResponse`](/sdk-reference/types/profile-lists#historylistresponse) — List of history items retrieved successfully

## Example

<CodeGroup>

```typescript TypeScript
import { DiscovrClient } from "discovr";
import type { HistoryListResponse } from "discovr";

const discovr = new DiscovrClient("your-client-id");

// After sign-in and profile selection …
const response: HistoryListResponse = await discovr.getHistoryItemsByMediaId("TV_1396", {
	season: 1,
	episode: 5,
	nextPageToken: "example",
	limit: 10,
});
console.log(response);
```
