---
title: "setRating()"
description: "Set a title's rating"
---

Sets the active profile's rating for a title to `liked`, `disliked`, or `super_liked`.

Ratings are mutually exclusive: setting a new rating automatically replaces any previous one. Setting the rating the title already has is a safe no-op.

Returns the title's updated `TitleState`, so you can update your UI immediately without calling `getTitleState` again.

**Auth tier:** session — send your session token in `Authorization: Bearer`.

## Parameters

| Name    | Type                                           | Required | Description                                                                  |
| ------- | ---------------------------------------------- | -------- | ---------------------------------------------------------------------------- |
| mediaId | `string`                                       | Yes      | The title's media ID (`MV_&lt;id&gt;` or `TV_&lt;id&gt;`), or an item `ref`. |
| value   | [`Rating`](/sdk-reference/types/common#rating) | Yes      |                                                                              |

## Example

<CodeGroup>

```typescript TypeScript
import { DiscovrClient } from "discovr";
import type { Rating, SetRatingPayload, TitleState } from "discovr";

const discovr = new DiscovrClient("your-client-id");

// After sign-in and profile selection …
const response: TitleState = await discovr.setRating("MV_550", "liked");
console.log(response);
```

}
