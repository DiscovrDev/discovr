---
title: "importHistory()"
description: "Import a watch history entry"
---

Imports a previously watched movie, show, season, or episode from an external source.

- `mediaId`: the title to import (`MV_&lt;number&gt;` for movies, `TV_&lt;number&gt;` for TV shows).
- `imported`: required string naming the external source (for example `"trakt"`).
- `updatedAt`: optional ISO 8601 timestamp of when it was watched. Defaults to now.
- `season` / `episode`: optional TV scope. Omit both to import all aired episodes of the show; pass `season` to import that season; pass both to import a single episode.

For live viewing use `scrobble()`, and for interactive "Mark as watched" buttons use `markWatched()`. To read watch history, use `GET /profile/titles?watched=true`.

Returns the title's updated `TitleState`.

**Auth tier:** session — send your session token in `Authorization: Bearer`.

## Parameters

| Name      | Type                 | Required | Description                                                                                                           |
| --------- | -------------------- | -------- | --------------------------------------------------------------------------------------------------------------------- |
| mediaId   | `string`             | Yes      | Full media ID (`MV_&lt;number&gt;` or `TV_&lt;number&gt;`), or an item `ref`.                                         |
| imported  | `string`             | Yes      | Name of the external source being imported from (for example `"trakt"`).                                              |
| updatedAt | `string (date-time)` | No       | ISO 8601 timestamp of when the title was watched. Defaults to now if omitted.                                         |
| season    | `integer`            | No       | TV only. Season number to import. Omit to import every aired episode of the show.                                     |
| episode   | `integer`            | No       | TV only, and only together with `season`. Episode number to import. Omit to import every aired episode of the season. |

## Returns

[`TitleState`](/sdk-reference/types/common#titlestate) — History imported; returns the title's new state.

## Example

<CodeGroup>

```typescript TypeScript
import { DiscovrClient } from "discovr";
import type { ImportHistoryPayload, TitleState } from "discovr";

const discovr = new DiscovrClient("your-client-id");

// After sign-in and profile selection …
const response: TitleState = await discovr.importHistory("TV_1396", "trakt", {
	updatedAt: "2023-01-15T20:00:00.000Z",
	season: 1,
	episode: 5,
});
console.log(response);
```
