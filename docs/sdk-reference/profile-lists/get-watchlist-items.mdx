---
title: "getWatchlistItems()"
description: "Get watchlist items"
---

Returns the profile's watchlist — titles saved to watch later.

**Auth tier:** session — send the session token from `POST /auth/session-token`.

Ordered by when they were added (newest first). Supports cursor-based pagination via `nextPageToken`.

**Pagination:**

- Pass `nextPageToken` from a previous response to fetch the next page.
- If `hasMore` is `true`, there are more items available.

## Parameters

| Name          | Type      | Required | Description                                           |
| ------------- | --------- | -------- | ----------------------------------------------------- |
| nextPageToken | `string`  | No       | Opaque token from previous page for pagination        |
| limit         | `integer` | No       | Maximum number of items to return (1-50, default: 10) |

## Returns

[`SimpleListResponse`](/sdk-reference/types/profile-lists#simplelistresponse) — List of watchlist items retrieved successfully

## Example

<CodeGroup>

```typescript TypeScript
import { DiscovrClient } from "discovr";
import type { SimpleListResponse } from "discovr";

const discovr = new DiscovrClient("your-client-id");

// After sign-in and profile selection …
const response: SimpleListResponse = await discovr.getWatchlistItems({
	nextPageToken: "example",
	limit: 10,
});
console.log(response);
```
