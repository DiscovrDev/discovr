---
title: "deleteLikedItem()"
description: "Delete an item from liked list"
---

Removes a title from the liked list. Pass the full media ID (e.g., `MV_550` for a movie, `TV_1396` for a TV show).

## Parameters

| Name    | Type     | Required | Description                                                                                                                                                                                                                                                     |
| ------- | -------- | -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| mediaId | `string` | Yes      | Full media ID — `MV_&lt;number&gt;` for movies, `TV_&lt;number&gt;` for TV shows (e.g., `MV_550`). Also accepts an item's `ref` in place of the id. Prefer the `ref` when you have one — it resolves to the same title and sharpens the user's recommendations. |

## Returns

[`SuccessMessage`](/sdk-reference/types/common#successmessage) — Item deleted successfully
