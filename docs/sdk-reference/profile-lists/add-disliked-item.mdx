---
title: "addDislikedItem()"
description: "Add an item to disliked list"
---

Adds a title to the disliked list.

**Auth tier:** session — send the session token from `POST /auth/session-token`.

Liked, disliked, and super-liked are exclusive — disliking something automatically removes any existing like or super-like for the same title.

Returns `201` if the item was newly added, `200` if it was already disliked.

## Parameters

| Name    | Type     | Required | Description                                                                                                                                                                                                                                                     |
| ------- | -------- | -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| mediaId | `string` | Yes      | Full media ID — `MV_&lt;number&gt;` for movies, `TV_&lt;number&gt;` for TV shows (e.g., `MV_550`). Also accepts an item's `ref` in place of the id. Prefer the `ref` when you have one — it resolves to the same title and sharpens the user's recommendations. |

## Returns

[`SuccessMessage`](/sdk-reference/types/common#successmessage) — Item was already disliked — no change made.
