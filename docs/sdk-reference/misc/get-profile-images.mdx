---
title: "getProfileImages()"
description: "List avatar images"
---

Returns publicly available avatar images for use in profile setup. Paginated — pass `nextToken` from the previous response as `pageToken` to load more. These are curated still images.

No authentication required.

## Parameters

| Name      | Type      | Required | Description                                                                                              |
| --------- | --------- | -------- | -------------------------------------------------------------------------------------------------------- |
| limit     | `integer` | No       | Maximum number of images to return (1–50).                                                               |
| pageToken | `string`  | No       | Pagination cursor from the `nextToken` field of the previous response. Omit to start from the beginning. |

## Returns

[`ProfileImagesResponse`](/sdk-reference/types/misc#profileimagesresponse) — Avatar images returned successfully.

<AccordionGroup>
<Accordion title="View response structure">
```json
{
  "nextToken": "string",
  "images": ["string"]
}
```
</Accordion>
