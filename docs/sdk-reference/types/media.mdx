## CastMember

<a id="castmember" />

One cast member of a title.

| Property     | Type      | Required | Description                                                                                                                                                |
| ------------ | --------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| id           | `integer` | Yes      | Catalogue identifier for the person. Stable across titles.                                                                                                 |
| name         | `string`  | Yes      | The person's name.                                                                                                                                         |
| character    | `string`  | No       | The role they play. `null` when the catalogue doesn't list one.                                                                                            |
| profile_path | `object`  | No       | Portrait URLs keyed by width bucket (`w45`, `w92`, `w154`, `w185`, `w300`, `w342`, `w500`, `w780`, `w1280`, `original`), or `null` when there is no photo. |

## CrewMember

<a id="crewmember" />

A director, writer or creator of a title.

| Property     | Type      | Required | Description                                                                                                                                                |
| ------------ | --------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| id           | `integer` | Yes      | Catalogue identifier for the person. Stable across titles.                                                                                                 |
| name         | `string`  | Yes      | The person's name.                                                                                                                                         |
| job          | `string`  | Yes      | Their role on the title, such as `Director`, `Screenplay`, `Writer` or `Creator`.                                                                          |
| profile_path | `object`  | No       | Portrait URLs keyed by width bucket (`w45`, `w92`, `w154`, `w185`, `w300`, `w342`, `w500`, `w780`, `w1280`, `original`), or `null` when there is no photo. |

## Episode

<a id="episode" />

Details for a single TV episode.

| Property        | Type                  | Required | Description                                                                                                                         |
| --------------- | --------------------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| episode_tmdb_id | `integer`             | Yes      | Numeric identifier for the episode.                                                                                                 |
| episode_number  | `integer`             | Yes      | Episode number within the season.                                                                                                   |
| name            | `string`              | Yes      | Episode title.                                                                                                                      |
| overview        | `string`              | No       | Episode synopsis.                                                                                                                   |
| still_path      | `object`              | No       | Episode still image URLs keyed by width bucket (`w45`, `w92`, `w154`, `w185`, `w300`, `w342`, `w500`, `w780`, `w1280`, `original`). |
| air_date        | `string`              | No       | Original air date of the episode, as `YYYY-MM-DD`, or `null` when unknown.                                                          |
| runtime         | `integer`             | No       | Episode runtime in minutes.                                                                                                         |
| season_number   | `integer`             | Yes      | Season this episode belongs to.                                                                                                     |
| show_id         | `string`              | Yes      | The parent TV show identifier (e.g., `TV_1396`).                                                                                    |
| production_code | `string`              | No       | Production code for the episode.                                                                                                    |
| vote_average    | `number`              | No       | Community rating for the episode.                                                                                                   |
| vote_count      | `integer`             | No       | Number of ratings for the episode.                                                                                                  |
| crew            | `EpisodeCrewMember[]` | No       | Crew members for this episode.                                                                                                      |
| guest_stars     | `EpisodeGuestStar[]`  | No       | Guest cast for this episode.                                                                                                        |

## MediaAssetsResponse

<a id="mediaassetsresponse" />

Best-available poster, backdrop, logo, and trailer for a title — one resolved URL per asset type.

| Property | Type     | Required | Description                                                                                                                                                                          |
| -------- | -------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| poster   | `object` | No       | Best poster image URLs keyed by width bucket (`w45`, `w92`, `w154`, `w185`, `w300`, `w342`, `w500`, `w780`, `w1280`, `original`), or null if no poster is available.                 |
| backdrop | `object` | No       | Best backdrop image URLs keyed by width bucket (`w45`, `w92`, `w154`, `w185`, `w300`, `w342`, `w500`, `w780`, `w1280`, `original`), or null if no backdrop is available.             |
| logo     | `object` | No       | Best title logo (English preferred) URLs keyed by width bucket (`w45`, `w92`, `w154`, `w185`, `w300`, `w342`, `w500`, `w780`, `w1280`, `original`), or null if no logo is available. |
| trailer  | `object` | No       | The best trailer or clip for this title, or `null` when no videos exist for this title.                                                                                              |

## MediaAssetsTrailer

<a id="mediaassetstrailer" />

The best trailer or clip for this title, picked from the available videos — prefers official YouTube trailers, then teasers, then clips, then the first available video.

| Property | Type     | Required | Description                                                                      |
| -------- | -------- | -------- | -------------------------------------------------------------------------------- |
| key      | `string` | Yes      | YouTube video identifier — append to `https://www.youtube.com/watch?v=` to play. |
| url      | `string` | Yes      | Full YouTube watch URL for this trailer.                                         |

## MediaCredits

<a id="mediacredits" />

Who is in a title and who made it. Cast is the top-billed 15, in billing order. Crew is limited to directors and writers, plus a show's creators for TV.

| Property | Type           | Required | Description                                                                                   |
| -------- | -------------- | -------- | --------------------------------------------------------------------------------------------- |
| cast     | `CastMember[]` | Yes      | Up to 15 top-billed cast members, in billing order.                                           |
| crew     | `CrewMember[]` | Yes      | Directors and writers. For TV it also lists the show's creators, with `job` set to `Creator`. |

## MediaExternalIds

<a id="mediaexternalids" />

The title's identifiers on other services, for deep links and cross-referencing.

| Property | Type      | Required | Description                                                             |
| -------- | --------- | -------- | ----------------------------------------------------------------------- |
| imdb_id  | `string`  | No       | IMDb identifier, such as `tt0133093`. `null` when none is known.        |
| tvdb_id  | `integer` | No       | TheTVDB identifier. TV only; `null` for movies and for shows with none. |

| movie           | `object`            | No       |                                                                                                                                                                                                                                                         |
| tv              | `object`            | No       |                                                                                                                                                                                                                                                         |

Use `GET /profile/titles/&#123;mediaId&#125;` with `providers=true` for a personalized, preference-filtered provider list. Provider data sourced from JustWatch. |
| credits         | `object`            | No       |                                                                                                                                                                                                                                                         |
| external_ids    | `object`            | No       |                                                                                                                                                                                                                                                         |

## MediaResponseMovie

<a id="mediaresponsemovie" />

Movie details — only present when `media_type` is `movie`.

| Property       | Type      | Required | Description                                                                                                                                     |
| -------------- | --------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| id             | `string`  | No       | The Discovr media ID for this movie — the `MV_&lt;id&gt;` value you pass to other endpoints.                                                    |
| tmdb_id        | `integer` | No       | Catalogue identifier for this movie, without the `MV_` prefix.                                                                                  |
| title          | `string`  | No       | Display title, localised where a translation is available.                                                                                      |
| original_title | `string`  | No       | Title in the movie's original language. Differs from `title` for translated releases.                                                           |
| overview       | `string`  | No       | Short synopsis, suitable for a detail sheet.                                                                                                    |
| poster_path    | `object`  | No       | Poster image URLs keyed by width bucket (`w45`, `w92`, `w154`, `w185`, `w300`, `w342`, `w500`, `w780`, `w1280`, `original`).                    |
| backdrop_path  | `object`  | No       | Backdrop image URLs keyed by width bucket (`w45`, `w92`, `w154`, `w185`, `w300`, `w342`, `w500`, `w780`, `w1280`, `original`).                  |
| release_date   | `string`  | No       | Theatrical or first release date, as `YYYY-MM-DD`, or `null` when unknown.                                                                      |
| runtime        | `integer` | No       | Length in whole minutes, or `null` when unknown.                                                                                                |
| vote_average   | `number`  | No       | Average audience rating out of 10.                                                                                                              |
| vote_count     | `integer` | No       | How many ratings `vote_average` is based on — useful for deciding whether to show the score at all.                                             |
| popularity     | `number`  | No       | Relative popularity score. Comparable between titles, but has no fixed upper bound, so treat it as a sort key rather than something to display. |
| genres         | `Genre[]` | No       | Genres this movie belongs to.                                                                                                                   |
| tagline        | `string`  | No       | Short marketing line, where one exists.                                                                                                         |
| status         | `string`  | No       | Release status, such as `Released`, `In Production`, or `Post Production`.                                                                      |
| budget         | `integer` | No       | Production budget in US dollars. `0` when unknown.                                                                                              |
| revenue        | `integer` | No       | Worldwide box office in US dollars. `0` when unknown.                                                                                           |
| homepage       | `string`  | No       | Official site for the movie, where one exists.                                                                                                  |
| imdb_id        | `string`  | No       | IMDb identifier, for linking out to IMDb.                                                                                                       |

## SimilarResult

Prefer it wherever you'd pass this title's `id` onward — opening its detail screen, adding it to a list. It works exactly like the `id` and sharpens the user's recommendations. Use it for the profile it was returned to; for anything you share, use the `id`. A bare `id` always works; `ref` is never required. |
| tmdb_id        | `integer`           | Yes      | The numeric ID for this title.                                                                                                                                                                                                                                                                                                                                                   |
| media_type     | `"movie"` \| `"tv"` | Yes      | Whether this result is a movie or TV show.                                                                                                                                                                                                                                                                                                                                       |
| title          | `string`            | No       | Title of the movie (only for movies)                                                                                                                                                                                                                                                                                                                                             |
| name           | `string`            | No       | Name of the TV show (only for TV shows)                                                                                                                                                                                                                                                                                                                                          |
| original_title | `string`            | No       | Original title of the movie (only for movies)                                                                                                                                                                                                                                                                                                                                    |
| original_name  | `string`            | No       | Original name of the TV show (only for TV shows)                                                                                                                                                                                                                                                                                                                                 |
| overview       | `string`            | No       | Overview or description                                                                                                                                                                                                                                                                                                                                                          |
| poster_path    | `object`            | No       | Poster image URLs keyed by width bucket (`w45`, `w92`, `w154`, `w185`, `w300`, `w342`, `w500`, `w780`, `w1280`, `original`).                                                                                                                                                                                                                                                     |
| backdrop_path  | `object`            | No       | Backdrop image URLs keyed by width bucket (`w45`, `w92`, `w154`, `w185`, `w300`, `w342`, `w500`, `w780`, `w1280`, `original`).                                                                                                                                                                                                                                                   |
| release_date   | `string`            | No       | Release date (only for movies), as `YYYY-MM-DD`, or `null` when unknown.                                                                                                                                                                                                                                                                                                         |
| first_air_date | `string`            | No       | First air date (only for TV shows), as `YYYY-MM-DD`, or `null` when unknown.                                                                                                                                                                                                                                                                                                     |
| popularity     | `number`            | No       | Popularity score                                                                                                                                                                                                                                                                                                                                                                 |
| vote_average   | `number`            | No       | Average vote rating                                                                                                                                                                                                                                                                                                                                                              |
| vote_count     | `integer`           | No       | Number of votes                                                                                                                                                                                                                                                                                                                                                                  |
