## AvatarMediaType

<a id="avatarmediatype" />

What kind of file `avatarUrl` points at, as a MIME type. Use it to choose between an image view and a video player, and to decide what can be animated, instead of guessing from the URL, since uploads have no file extension. `image/gif`, `video/mp4` and `video/webm` are animated; the others are still.

On a profile it is absent when the type couldn't be determined; treat that as a still image. When you create or update a profile it is optional: Discovr works it out from the URL's file extension, so send it only when your URL has none. It can only be sent together with `avatarUrl`, and changing `avatarUrl` replaces it (or clears it when the new URL can't be typed), so it never describes the previous picture.

Allowed values: `"image/png"`, `"image/jpeg"`, `"image/webp"`, `"image/gif"`, `"video/mp4"`, `"video/webm"`

## MediaItem

<a id="mediaitem" />

A title in a row or the hero, with display metadata. The hero is a placement, not a type: its items are `MediaItem`s too.

| Property          | Type                | Required | Description                                                                                                                                                                                                                                                                                                                                                                                    |
| ----------------- | ------------------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| id                | `string`            | Yes      | Unique identifier for the media item                                                                                                                                                                                                                                                                                                                                                           |
| title             | `string`            | Yes      | Title of the media item                                                                                                                                                                                                                                                                                                                                                                        |
| overview          | `string`            | Yes      | Synopsis/summary text for this title.                                                                                                                                                                                                                                                                                                                                                          |
| poster_path       | `object`            | No       | Poster image URLs keyed by width bucket (`w45`, `w92`, `w154`, `w185`, `w300`, `w342`, `w500`, `w780`, `w1280`, `original`).                                                                                                                                                                                                                                                                   |
| backdrop_path     | `object`            | No       | Backdrop image URLs keyed by width bucket (`w45`, `w92`, `w154`, `w185`, `w300`, `w342`, `w500`, `w780`, `w1280`, `original`).                                                                                                                                                                                                                                                                 |
| media_type        | `"movie"` \| `"tv"` | Yes      | Type of media                                                                                                                                                                                                                                                                                                                                                                                  |
| year              | `integer`           | No       | Release year (the first air year for TV). Absent when the title has no date.                                                                                                                                                                                                                                                                                                                   |
| rating            | `number`            | No       | Average viewer rating out of 10, to one decimal. Absent until a title has votes.                                                                                                                                                                                                                                                                                                               |
| genres            | `string[]`          | No       | Genre names, most relevant first. Absent when none are known.                                                                                                                                                                                                                                                                                                                                  |
| logo_path         | `object`            | No       | Title logo image URLs (English preferred) keyed by width bucket (`w45`, `w92`, `w154`, `w185`, `w300`, `w342`, `w500`, `w780`, `w1280`, `original`). `null` when the title has no logo. Always present on `hero` items. On row items it is added when the items are served, and is absent only if the catalogue couldn't be reached for that title; fetch the row's items again to fill it in. |
| trailer           | `object`            | No       | The best trailer for the title, picked the same way as `getMediaAssets`. `null` when it has none. Added to row items when they are served; absent under the same conditions as `logo_path`.                                                                                                                                                                                                    |
| runtime           | `integer`           | No       | Running time in minutes. Movies only, and absent when the catalogue has none. Added to row items when they are served.                                                                                                                                                                                                                                                                         |
| number_of_seasons | `integer`           | No       | How many seasons the show has. TV only, and absent when the catalogue has none. Added to row items when they are served.                                                                                                                                                                                                                                                                       |
| type              | `"media"`           | Yes      | Discriminator field indicating this is a media item                                                                                                                                                                                                                                                                                                                                            |
| ref               | `string`            | No       | This item's `id` with the place it was shown attached. Prefer it wherever you'd pass this item's `id` onward — opening its detail screen, adding it to a list, scrobbling it. It works exactly like the `id` and sharpens the user's recommendations. Use it for the profile it was returned to; for anything you share, use the `id`. A bare `id` always works; `ref` is never required.      |

## MediaItemTrailer

<a id="mediaitemtrailer" />

| Property | Type     | Required | Description               |

| key      | `string` | Yes      | YouTube video identifier. |
| url      | `string` | Yes      | Full YouTube watch URL.   |

## MediaItemType

<a id="mediaitemtype" />

Discriminator value indicating a media item

Allowed values: `"media"`

## ProviderInfo

<a id="providerinfo" />

A streaming service and the regions where this title is available on it.

| Property | Type     | Required | Description                                                                                    |
| -------- | -------- | -------- | ---------------------------------------------------------------------------------------------- |
| id       | `string` | Yes      | Provider identifier.                                                                           |
| title    | `string` | Yes      | Display name of the streaming service.                                                         |
| logos    | `object` | Yes      | Square logo images at various sizes, keyed by pixel dimension.                                 |
| regions  | `object` | Yes      | Regions where this provider has the title available, keyed by ISO 3166-1 alpha-2 country code. |

## Rating

<a id="rating" />

One of the three mutually exclusive ratings a profile can give a title.

Allowed values: `"liked"`, `"disliked"`, `"super_liked"`

## TitlePlayback

<a id="titleplayback" />

The active profile's live resume position for an in-progress title.

| Property  | Type      | Required | Description                                                                  |
| --------- | --------- | -------- | ---------------------------------------------------------------------------- |
| progress  | `number`  | No       | How far through the movie or episode the viewer is, as a percentage (0–100). |
| season    | `integer` | No       | Season number of the episode currently being watched (TV shows only).        |
| episode   | `integer` | No       | Episode number currently being watched (TV shows only).                      |
| updatedAt | `string`  | Yes      | When this position was last recorded.                                        |

## TitleState

<a id="titlestate" />

The active profile's complete state for a title — returned by `getTitleState` and by every title state write.

| Property         | Type                                         | Required | Description                                                                                                                                                      |
| ---------------- | -------------------------------------------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| mediaId          | `string`                                     | Yes      | The title's media ID (`MV_&lt;id&gt;` or `TV_&lt;id&gt;`).                                                                                                       |
| mediaType        | `"movie"` \| `"tv"`                          | Yes      | Whether this title is a movie or a TV show.                                                                                                                      |
| rating           | `"liked"` \| `"disliked"` \| `"super_liked"` | No       | The profile's rating (`liked`, `disliked`, `super_liked`), or `null` if unrated.                                                                                 |
| watchlist        | `boolean`                                    | Yes      | Whether the title is on the profile's watchlist.                                                                                                                 |
| watched          | `boolean`                                    | Yes      | Whether the profile has played any of this title, even briefly. Use `completed` for a "Watched" checkmark.                                                       |
| completed        | `boolean`                                    | Yes      | Whether the profile has finished the title (≥ 80% for a movie; every aired episode of every regular season for a TV show; specials excluded).                    |
| completedSeasons | `integer[]`                                  | No       | TV shows only — regular season numbers (1 and up) whose aired episodes are all watched.                                                                          |
| episodes         | `object`                                     | No       | TV shows only — map from season number (as string) to sorted watched episode numbers.                                                                            |
| plays            | `integer`                                    | Yes      | Number of completed plays (of the movie or of episodes).                                                                                                         |
| playback         | `object`                                     | No       | Live resume position if the viewer is currently mid-watch, or `null` otherwise.                                                                                  |
| providers        | `ProviderInfo[]`                             | No       | Streaming services where this title is available, filtered to the account's selected providers. Present only when `providers=true` is passed to `getTitleState`. |
