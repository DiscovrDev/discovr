## KnownForItem

<a id="knownforitem" />

A title a person is known for, returned alongside `person` search results.

| Property       | Type                | Required | Description                                                                                                                                                                                                                                                                                                                                                                   |
| -------------- | ------------------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| id             | `string`            | Yes      | Unique identifier — `TV_&lt;id&gt;` for TV shows, `MV_&lt;id&gt;` for movies. Ready to pass to `/media/&#123;mediaId&#125;`.                                                                                                                                                                                                                                                  |
| ref            | `string`            | No       | This title's `id` with the search it came from attached. Prefer it wherever you'd pass this title's `id` onward — opening its detail screen, adding it to a list. It works exactly like the `id` and sharpens the user's recommendations. Use it for the profile it was returned to; for anything you share, use the `id`. A bare `id` always works; `ref` is never required. |
| tmdb_id        | `integer`           | Yes      | The numeric ID for this title.                                                                                                                                                                                                                                                                                                                                                |
| media_type     | `"movie"` \| `"tv"` | Yes      | Whether this title is a movie or a TV show.                                                                                                                                                                                                                                                                                                                                   |
| title          | `string`            | No       | Movie title. TV shows use `name` instead.                                                                                                                                                                                                                                                                                                                                     |
| name           | `string`            | No       | TV show name. Movies use `title` instead.                                                                                                                                                                                                                                                                                                                                     |
| overview       | `string`            | No       | Short synopsis of the title.                                                                                                                                                                                                                                                                                                                                                  |
| poster_path    | `object`            | No       | Poster image URLs keyed by width bucket (`w45`, `w92`, `w154`, `w185`, `w300`, `w342`, `w500`, `w780`, `w1280`, `original`).                                                                                                                                                                                                                                                  |
| backdrop_path  | `object`            | No       | Backdrop image URLs keyed by width bucket (`w45`, `w92`, `w154`, `w185`, `w300`, `w342`, `w500`, `w780`, `w1280`, `original`).                                                                                                                                                                                                                                                |
| release_date   | `string`            | No       | Release date, for movies.                                                                                                                                                                                                                                                                                                                                                     |
| first_air_date | `string`            | No       | First air date, for TV shows.                                                                                                                                                                                                                                                                                                                                                 |
| vote_average   | `number`            | No       | Average audience rating out of 10.                                                                                                                                                                                                                                                                                                                                            |

## SearchResponse

<a id="searchresponse" />

A page of search results.

There is no total result count — use `has_more` to page instead.

| Property | Type             | Required | Description                                                          |
| -------- | ---------------- | -------- | -------------------------------------------------------------------- |
| page     | `integer`        | Yes      | The page these results came from, starting at 1.                     |
| results  | `SearchResult[]` | Yes      | Matched results for the current page, ordered by relevance.          |
| has_more | `boolean`        | Yes      | Whether another page is available. Request it by passing `page` + 1. |

## SearchResult

<a id="searchresult" />

A single search result — could be a movie, TV show, or person.

| Property             | Type                              | Required | Description                                                                                                                                                                                                                                                                                                                                                                                                                          |
| -------------------- | --------------------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| id                   | `string`                          | Yes      | Unique identifier. `TV_&lt;id&gt;` for TV shows, `MV_&lt;id&gt;` for movies, or the raw numeric ID for people.                                                                                                                                                                                                                                                                                                                       |
| tmdb_id              | `integer`                         | Yes      | The numeric ID for this title or person.                                                                                                                                                                                                                                                                                                                                                                                             |
| media_type           | `"movie"` \| `"tv"` \| `"person"` | Yes      | Whether this result is a movie, TV show, or person.                                                                                                                                                                                                                                                                                                                                                                                  |
| ref                  | `string`                          | No       | This result's `id` with the search it came from attached. Prefer it wherever you'd pass this result's `id` onward — opening its detail screen, adding it to a list. It works exactly like the `id` and sharpens the user's recommendations. Use it for the profile it was returned to; for anything you share, use the `id`. Absent on people, who have no detail screen to open. A bare `id` always works; `ref` is never required. |
| title                | `string`                          | No       | Movie title. TV shows use `name`, people use `name` too.                                                                                                                                                                                                                                                                                                                                                                             |
| name                 | `string`                          | No       | Show or person name. Movies use `title` instead.                                                                                                                                                                                                                                                                                                                                                                                     |
| original_title       | `string`                          | No       | Movie title in its original language.                                                                                                                                                                                                                                                                                                                                                                                                |
| original_name        | `string`                          | No       | Show name in its original language.                                                                                                                                                                                                                                                                                                                                                                                                  |
| overview             | `string`                          | No       | Short synopsis. Not present for `person` results.                                                                                                                                                                                                                                                                                                                                                                                    |
| poster_path          | `object`                          | No       | Poster image URLs keyed by width bucket (`w45`, `w92`, `w154`, `w185`, `w300`, `w342`, `w500`, `w780`, `w1280`, `original`). Absent for `person` results.                                                                                                                                                                                                                                                                            |
| backdrop_path        | `object`                          | No       | Backdrop image URLs keyed by width bucket (`w45`, `w92`, `w154`, `w185`, `w300`, `w342`, `w500`, `w780`, `w1280`, `original`). Absent for `person` results.                                                                                                                                                                                                                                                                          |
| release_date         | `string`                          | No       | Release date for `movie` results, as `YYYY-MM-DD`.                                                                                                                                                                                                                                                                                                                                                                                   |
| first_air_date       | `string`                          | No       | First air date for `tv` results, as `YYYY-MM-DD`.                                                                                                                                                                                                                                                                                                                                                                                    |
| popularity           | `number`                          | No       | Relative popularity score. Comparable between results, but has no fixed upper bound, so treat it as a sort key rather than something to display.                                                                                                                                                                                                                                                                                     |
| vote_average         | `number`                          | No       | Average audience rating out of 10. Not present for `person` results.                                                                                                                                                                                                                                                                                                                                                                 |
| vote_count           | `integer`                         | No       | How many ratings `vote_average` is based on. Not present for `person` results.                                                                                                                                                                                                                                                                                                                                                       |
| profile_path         | `object`                          | No       | Headshot image URLs keyed by width bucket (`w45`, `w92`, `w154`, `w185`, `w300`, `w342`, `w500`, `w780`, `w1280`, `original`). Only present for `person` results.                                                                                                                                                                                                                                                                    |
| known_for_department | `string`                          | No       | The department this person is best known for, e.g. `Acting` or `Directing`.                                                                                                                                                                                                                                                                                                                                                          |
| known_for            | `KnownForItem[]`                  | No       | A few titles this person is best known for. Only present for `person` results. Because a person has no detail view of its own, these are the natural next step after a person result — each carries an `id` you can pass straight to `/media/&#123;mediaId&#125;`.                                                                                                                                                                   |
