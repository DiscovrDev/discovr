## ImportHistoryPayload

<a id="importhistorypayload" />

A watch history entry to import from an external source.

| Property  | Type      | Required | Description                                                                                                           |
| --------- | --------- | -------- | --------------------------------------------------------------------------------------------------------------------- |
| mediaId   | `string`  | Yes      | Full media ID (`MV_&lt;number&gt;` or `TV_&lt;number&gt;`), or an item `ref`.                                         |
| imported  | `string`  | Yes      | Name of the external source being imported from (for example `"trakt"`).                                              |
| updatedAt | `string`  | No       | ISO 8601 timestamp of when the title was watched. Defaults to now if omitted.                                         |
| season    | `integer` | No       | TV only. Season number to import. Omit to import every aired episode of the show.                                     |
| episode   | `integer` | No       | TV only, and only together with `season`. Episode number to import. Omit to import every aired episode of the season. |

## PlaybackItem

<a id="playbackitem" />

A media item with live playback progress. `progress` is 0–100.

| Property      | Type                | Required | Description                                                                                                                                                                                                                                       |
| ------------- | ------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| id            | `string`            | Yes      | The DiscovrID (`TV_&lt;number&gt;` or `MV_&lt;number&gt;`).                                                                                                                                                                                       |
| ref           | `string`            | No       | This item's `id` with the list it came from attached. Prefer it wherever you'd pass this item's `id` onward — opening its detail screen, scrobbling it, or removing it from Continue Watching. A bare `id` always works; `ref` is never required. |
| mediaType     | `"movie"` \| `"tv"` | Yes      | The type of media.                                                                                                                                                                                                                                |
| title         | `string`            | Yes      | The title of the media.                                                                                                                                                                                                                           |
| poster_path   | `object`            | Yes      | Poster image URLs keyed by width bucket (`w45`, `w92`, `w154`, `w185`, `w300`, `w342`, `w500`, `w780`, `w1280`, `original`).                                                                                                                      |
| backdrop_path | `object`            | Yes      | Backdrop image URLs keyed by width bucket (`w45`, `w92`, `w154`, `w185`, `w300`, `w342`, `w500`, `w780`, `w1280`, `original`).                                                                                                                    |
| episode_image | `object`            | No       | Episode still image URLs keyed by width bucket. Only present for episode-level playback items.                                                                                                                                                    |
| episode_title | `string`            | No       | The title of the episode (only present for episode-level playback items).                                                                                                                                                                         |
| progress      | `number`            | No       | Playback progress percentage (0–100).                                                                                                                                                                                                             |
| updatedAt     | `string`            | No       | ISO 8601 timestamp indicating when playback was last updated.                                                                                                                                                                                     |
| season        | `integer`           | No       | Season number (only for TV shows).                                                                                                                                                                                                                |
| episode       | `integer`           | No       | Episode number (only for TV shows).                                                                                                                                                                                                               |
| createdAt     | `string`            | Yes      | ISO 8601 timestamp indicating when the item was first added to Continue Watching.                                                                                                                                                                 |

## PlaybackListResponse

<a id="playbacklistresponse" />

Paginated list of items with live playback progress.

| Property      | Type             | Required | Description                                     |
| ------------- | ---------------- | -------- | ----------------------------------------------- |
| items         | `PlaybackItem[]` | Yes      | Array of playback items.                        |
| hasMore       | `boolean`        | Yes      | Whether there are more items available.         |
| nextPageToken | `string`         | No       | Opaque token to fetch the next page of results. |

## SeasonEpisodeState

<a id="seasonepisodestate" />

Whether the active profile has finished one episode of a season.

| Property  | Type      | Required | Description                                    |
| --------- | --------- | -------- | ---------------------------------------------- |
| episode   | `integer` | Yes      | Episode number within the season.              |
| completed | `boolean` | Yes      | Whether the profile has finished this episode. |

## SeasonState

<a id="seasonstate" />

Per-episode completion state for one TV season, plus whether the season as a whole is complete.

| Property  | Type                   | Required | Description                                            |
| --------- | ---------------------- | -------- | ------------------------------------------------------ |
| season    | `integer`              | Yes      | The season number.                                     |
| completed | `boolean`              | Yes      | Whether every aired episode of this season is watched. |
| episodes  | `SeasonEpisodeState[]` | Yes      | Completion state for every episode in the season.      |

## SetRatingPayload

<a id="setratingpayload" />

The rating to set on a title.

| Property | Type                                         | Required | Description |
| -------- | -------------------------------------------- | -------- | ----------- |
| value    | `"liked"` \| `"disliked"` \| `"super_liked"` | Yes      |             |

## SuccessMessage

<a id="successmessage" />

Confirmation response for deletions that do not return a title state object.

| Property | Type     | Required | Description      |
| -------- | -------- | -------- | ---------------- |
| message  | `string` | Yes      | Success message. |

## TitleListItem

<a id="titlelistitem" />

A title from a profile's rating, watchlist, or watch-history list, with display artwork and state summary.

| Property      | Type                                         | Required | Description                                                                                                                                                                                                                        |
| ------------- | -------------------------------------------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| id            | `string`                                     | Yes      | The DiscovrID (`TV_&lt;number&gt;` or `MV_&lt;number&gt;`).                                                                                                                                                                        |
| ref           | `string`                                     | No       | This item's `id` with the list it came from attached. Prefer it wherever you'd pass this item's `id` onward — opening its detail screen, rating it, or removing it from a list. A bare `id` always works; `ref` is never required. |
| mediaType     | `"movie"` \| `"tv"`                          | Yes      | The type of media.                                                                                                                                                                                                                 |
| title         | `string`                                     | Yes      | The title of the media.                                                                                                                                                                                                            |
| poster_path   | `object`                                     | Yes      | Poster image URLs keyed by width bucket (`w45`, `w92`, `w154`, `w185`, `w300`, `w342`, `w500`, `w780`, `w1280`, `original`).                                                                                                       |
| backdrop_path | `object`                                     | Yes      | Backdrop image URLs keyed by width bucket (`w45`, `w92`, `w154`, `w185`, `w300`, `w342`, `w500`, `w780`, `w1280`, `original`).                                                                                                     |
| rating        | `"liked"` \| `"disliked"` \| `"super_liked"` | No       | The profile's rating for this title, or `null` if unrated.                                                                                                                                                                         |
| watchlist     | `boolean`                                    | Yes      | Whether this title is on the profile's watchlist.                                                                                                                                                                                  |
| updatedAt     | `string`                                     | Yes      | ISO 8601 timestamp for the active sort dimension (rated time, watchlisted time, or last watched time).                                                                                                                             |
| completed     | `boolean`                                    | No       | Present on `watched=true` results — whether the title is fully finished.                                                                                                                                                           |
| plays         | `integer`                                    | No       | Present on `watched=true` results — total completed plays.                                                                                                                                                                         |
| season        | `integer`                                    | No       | Present on `watched=true` TV results — most recently watched season number.                                                                                                                                                        |
| episode       | `integer`                                    | No       | Present on `watched=true` TV results — most recently watched episode number.                                                                                                                                                       |
| imported      | `string`                                     | No       | Present on `watched=true` results when imported from an external source (e.g., `"trakt"`).                                                                                                                                         |

## TitleListResponse

<a id="titlelistresponse" />

Paginated list of titles. Pass `nextPageToken` to fetch the next page.

| Property      | Type              | Required | Description                                     |
| ------------- | ----------------- | -------- | ----------------------------------------------- |
| items         | `TitleListItem[]` | Yes      | Array of title list items.                      |
| hasMore       | `boolean`         | Yes      | Whether more items are available.               |
| nextPageToken | `string`          | No       | Opaque token to fetch the next page of results. |
