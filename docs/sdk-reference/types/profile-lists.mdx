## AddHistoryPayload

<a id="addhistorypayload" />

A watch history entry to record. For TV shows, `season` is required; `episode` is optional.

| Property  | Type      | Required | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| --------- | --------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| mediaId   | `string`  | Yes      | Full media ID — `MV_&lt;number&gt;` for movies, `TV_&lt;number&gt;` for TV shows (e.g., `TV_1396`). Also accepts an item's `ref` in place of the id. Prefer the `ref` when you have one — it resolves to the same title and sharpens the user's recommendations.                                                                                                                                                                                                                                                                                  |
| updatedAt | `string`  | No       | ISO 8601 timestamp indicating when the history entry was last updated                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| progress  | `number`  | No       | Playback progress percentage (0-100)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| season    | `integer` | No       | Season number (required for TV shows)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| episode   | `integer` | No       | Episode number (optional for TV shows). When omitted, creates a "Default for Episode" entry that applies to all episodes in the season where episode.air_date &lt; historyItem.updatedAt. This allows updating multiple episodes with a single history entry. **Overriding Season Defaults:** When provided, creates an explicit episode entry that takes precedence over any season default entries. To unmark an episode completed via season default, create an explicit entry with progress &lt; 80% (which will not be marked as completed). |
| imported  | `string`  | No       | Source of import (e.g., "trakt") if this item was imported                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |

## AddPlaybackPayload

<a id="addplaybackpayload" />

Playback progress to record. `progress` is 0–100. `updatedAt` is an ISO timestamp from the client — use the actual time of the progress update.

| Property  | Type     | Required | Description                                                                                                                                                                                                                                                     |
| --------- | -------- | -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| mediaId   | `string` | Yes      | Full media ID — `MV_&lt;number&gt;` for movies, `TV_&lt;number&gt;` for TV shows (e.g., `MV_550`). Also accepts an item's `ref` in place of the id. Prefer the `ref` when you have one — it resolves to the same title and sharpens the user's recommendations. |
| progress  | `number` | No       | Initial playback progress percentage (0-100)                                                                                                                                                                                                                    |
| updatedAt | `string` | No       | ISO 8601 timestamp for when playback was last updated                                                                                                                                                                                                           |

## AddSimpleListItemPayload

<a id="addsimplelistitempayload" />

The media item to add. Use the full Discovr media ID — `MV_&lt;id&gt;` for movies, `TV_&lt;id&gt;` for TV shows.

| Property | Type     | Required | Description                                                                                                                                                                                                                                                     |
| -------- | -------- | -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| mediaId  | `string` | Yes      | Full media ID — `MV_&lt;number&gt;` for movies, `TV_&lt;number&gt;` for TV shows (e.g., `MV_550`). Also accepts an item's `ref` in place of the id. Prefer the `ref` when you have one — it resolves to the same title and sharpens the user's recommendations. |

## EditPlaybackPayload

<a id="editplaybackpayload" />

Updated playback progress. Provide at least one of `progress` or `updatedAt`. `mediaId` identifies the entry to update.

| Property  | Type     | Required | Description                                                                                                                                                                                                                                                     |
| --------- | -------- | -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| mediaId   | `string` | Yes      | Full media ID — `MV_&lt;number&gt;` for movies, `TV_&lt;number&gt;` for TV shows (e.g., `MV_550`). Also accepts an item's `ref` in place of the id. Prefer the `ref` when you have one — it resolves to the same title and sharpens the user's recommendations. |
| progress  | `number` | No       | New playback progress percentage (0-100)                                                                                                                                                                                                                        |
| updatedAt | `string` | No       | ISO 8601 timestamp for when playback was last updated                                                                                                                                                                                                           |

## HistoryItem

<a id="historyitem" />

A watch history entry. TV shows include season and episode.

| Property      | Type                | Required | Description                                                                                                                                                                                                                                                                                                                                                                           |
| ------------- | ------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| id            | `string`            | Yes      | The DiscovrID (TV*&lt;number&gt; or MV*&lt;number&gt;)                                                                                                                                                                                                                                                                                                                                |
| ref           | `string`            | No       | This entry's `id` with the list it came from attached. Prefer it wherever you'd pass this entry's `id` onward — opening its detail screen, removing it from your history. It works exactly like the `id` and sharpens the user's recommendations. Use it for the profile it was returned to; for anything you share, use the `id`. A bare `id` always works; `ref` is never required. |
| mediaType     | `"movie"` \| `"tv"` | Yes      | The type of media                                                                                                                                                                                                                                                                                                                                                                     |
| title         | `string`            | Yes      | The title of the media                                                                                                                                                                                                                                                                                                                                                                |
| poster_path   | `object`            | Yes      | Poster image URLs keyed by width bucket (`w45`, `w92`, `w154`, `w185`, `w300`, `w342`, `w500`, `w780`, `w1280`, `original`).                                                                                                                                                                                                                                                          |
| backdrop_path | `object`            | Yes      | Backdrop image URLs keyed by width bucket (`w45`, `w92`, `w154`, `w185`, `w300`, `w342`, `w500`, `w780`, `w1280`, `original`).                                                                                                                                                                                                                                                        |
| updatedAt     | `string`            | Yes      | ISO 8601 timestamp indicating when the history entry was last updated                                                                                                                                                                                                                                                                                                                 |
| progress      | `number`            | No       | Playback progress percentage (0-100)                                                                                                                                                                                                                                                                                                                                                  |
| completed     | `boolean`           | Yes      | Whether the media is considered completed (progress &gt;= 80%)                                                                                                                                                                                                                                                                                                                        |
| watched_count | `integer`           | Yes      | How many times the profile has finished this title (or episode). `0` means it has been started but not finished.                                                                                                                                                                                                                                                                      |
| season        | `integer`           | No       | Season number (required for TV shows)                                                                                                                                                                                                                                                                                                                                                 |
| episode       | `integer`           | No       | Episode number (required for TV shows)                                                                                                                                                                                                                                                                                                                                                |
| imported      | `string`            | No       | Source of import (e.g., "trakt") if this item was imported                                                                                                                                                                                                                                                                                                                            |
| createdAt     | `string`            | Yes      | ISO 8601 timestamp indicating when the item was added to the list                                                                                                                                                                                                                                                                                                                     |

## HistoryListResponse

<a id="historylistresponse" />

Paginated list of watch history entries.

| Property      | Type            | Required | Description                                    |
| ------------- | --------------- | -------- | ---------------------------------------------- |
| items         | `HistoryItem[]` | Yes      | Array of history items                         |
| hasMore       | `boolean`       | Yes      | Whether there are more items available         |
| nextPageToken | `string`        | No       | Opaque token to fetch the next page of results |

## PatchHistoryPayload

<a id="patchhistorypayload" />

Updates the recorded progress for a title already in the profile's history.

| Property | Type     | Required | Description                                                                                                                                                                                     |
| -------- | -------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| progress | `number` | Yes      | Playback progress percentage (0-100). Values &gt;= 80% are considered completed, values &lt; 80% are not completed. Use progress: 0 to unmark an episode that was completed via season default. |

## PlaybackItem

<a id="playbackitem" />

A media item with playback progress. `progress` is 0–100.

| Property      | Type                | Required | Description                                                                                                                                                                                                                                                                                                                                                                                  |
| ------------- | ------------------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| id            | `string`            | Yes      | The DiscovrID (TV*&lt;number&gt; or MV*&lt;number&gt;)                                                                                                                                                                                                                                                                                                                                       |
| ref           | `string`            | No       | This item's `id` with the list it came from attached. Prefer it wherever you'd pass this item's `id` onward — opening its detail screen, scrobbling it, removing it from a list. It works exactly like the `id` and sharpens the user's recommendations. Use it for the profile it was returned to; for anything you share, use the `id`. A bare `id` always works; `ref` is never required. |
| mediaType     | `"movie"` \| `"tv"` | Yes      | The type of media                                                                                                                                                                                                                                                                                                                                                                            |
| title         | `string`            | Yes      | The title of the media                                                                                                                                                                                                                                                                                                                                                                       |
| poster_path   | `object`            | Yes      | Poster image URLs keyed by width bucket (`w45`, `w92`, `w154`, `w185`, `w300`, `w342`, `w500`, `w780`, `w1280`, `original`).                                                                                                                                                                                                                                                                 |
| backdrop_path | `object`            | Yes      | Backdrop image URLs keyed by width bucket (`w45`, `w92`, `w154`, `w185`, `w300`, `w342`, `w500`, `w780`, `w1280`, `original`).                                                                                                                                                                                                                                                               |
| episode_image | `object`            | No       | Episode still image URLs keyed by width bucket (`w45`, `w92`, `w154`, `w185`, `w300`, `w342`, `w500`, `w780`, `w1280`, `original`). Only present for episode-level playback items.                                                                                                                                                                                                           |
| episode_title | `string`            | No       | The title of the episode (only present for episode-level playback items)                                                                                                                                                                                                                                                                                                                     |
| progress      | `number`            | No       | Playback progress percentage (0-100)                                                                                                                                                                                                                                                                                                                                                         |
| updatedAt     | `string`            | No       | ISO 8601 timestamp indicating when playback was last updated                                                                                                                                                                                                                                                                                                                                 |
| season        | `integer`           | No       | Season number (only for TV shows)                                                                                                                                                                                                                                                                                                                                                            |
| episode       | `integer`           | No       | Episode number (only for TV shows)                                                                                                                                                                                                                                                                                                                                                           |
| createdAt     | `string`            | Yes      | ISO 8601 timestamp indicating when the item was first added to the list                                                                                                                                                                                                                                                                                                                      |
