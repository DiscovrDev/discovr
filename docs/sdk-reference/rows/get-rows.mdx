---
title: "getRows()"
description: "List rows"
---

Returns paginated rows for a page. Each row is a labeled group of media titles — the building blocks of your recommendation UI.

Row IDs are opaque references — pass them straight back to `GET /pages/&#123;pageId&#125;/rows/&#123;rowId&#125;/items`. They keep working even if recommendations refresh while the user is scrolling, so a rail they've already opened stays readable to the end.

Pagination continues in the set of results it started with, and only for as long as the user's recommendations haven't turned over. After a turnover (or, rarely, once the set has been cleaned up) the token is refused with `409 CURSOR_EXPIRED`: call `getPage` and `getRows` with no token on the same page ID and replace what you're showing with the result. Rows you already hold are not affected: `GET /pages/&#123;pageId&#125;/rows/&#123;rowId&#125;/items` keeps working for them.

**Auth tier:** session.

## Parameters

| Name          | Type      | Required | Description                                             |
| ------------- | --------- | -------- | ------------------------------------------------------- |
| pageId        | `string`  | Yes      | The unique identifier of the page                       |
| nextPageToken | `string`  | No       | Opaque pagination token returned from the previous page |
| limit         | `integer` | No       | Maximum number of rows to return                        |

## Returns

[`GetRowsResponse`](/sdk-reference/types/rows#getrowsresponse) — List of rows retrieved successfully

## Example

<CodeGroup>

```typescript TypeScript
import { DiscovrClient } from "discovr";
import type { GetRowsResponse } from "discovr";

const discovr = new DiscovrClient("your-client-id");

// After sign-in and profile selection …
const response: GetRowsResponse = await discovr.getRows("example", {
	nextPageToken: "example",
	limit: 5,
});
console.log(response);
```
