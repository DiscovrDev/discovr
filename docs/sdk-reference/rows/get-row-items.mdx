---
title: "getRowItems()"
description: "List row items"
---

Returns paginated items within a row. Items include the full display metadata needed to render a media card — title, poster, backdrop, type, and more.

Row IDs stay valid across a recommendations refresh, so a user can finish scrolling a rail they've already opened.

**Auth tier:** session.

## Parameters

| Name          | Type      | Required | Description                                             |
| ------------- | --------- | -------- | ------------------------------------------------------- |
| pageId        | `string`  | Yes      | The unique identifier of the page                       |
| rowId         | `string`  | Yes      | The unique identifier of the row                        |
| nextPageToken | `string`  | No       | Opaque pagination token returned from the previous page |
| limit         | `integer` | No       | Maximum number of items to return                       |

## Returns

[`GetRowItemsResponse`](/sdk-reference/types/rows#getrowitemsresponse) — List of row items retrieved successfully

## Example

<CodeGroup>

```typescript TypeScript
import { DiscovrClient } from "discovr";
import type { GetRowItemsResponse } from "discovr";

const discovr = new DiscovrClient("your-client-id");

// After sign-in and profile selection …
const response: GetRowItemsResponse = await discovr.getRowItems("example", "example", {
	nextPageToken: "example",
	limit: 10,
});
console.log(response);
```
