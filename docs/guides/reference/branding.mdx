You've set up authentication. Now you need a sign-in button that looks right in your app. Discovr gives you the logos, colors, and patterns to build one that feels at home — whether it's a pill button on a landing page or a compact inline option.

Once your button is ready, wire it up to the [Web Sign-in Flow](/guides/authentication/web-sign-in) or [Device Code Flow](/guides/authentication/device-code).

## The :Discovr brand mark

You'll notice we style the brand name with a colon prefix — **:Discovr** — in text and marketing. The colon is intentional branding, a nod to media metadata notation. Feel free to use this style in your own copy when referring to the platform (e.g., "Powered by :Discovr" or "Sign in with :Discovr").

In button UI, the wordmark SVG _is_ the `:Discovr` — you don't need to add the colon separately.

## Colors

| Token                                      | Light     | Dark      |
| ------------------------------------------ | --------- | --------- |
| **Ink** — button bg, border, text on light | `#1A1A1A` | `#EAEAEA` |
| **Canvas** — button text and fg on Ink     | `#F4F1EA` | `#2F2F2F` |

**Hover:** `opacity: 0.9`. Works for solid and outlined styles alike.

**Disabled / loading:** `opacity: 0.5` + `pointer-events: none`. Swap label to `"Signing in…"`.

**Font:** DM Sans (or system sans-serif), 14 px, weight 500.

---

## A few things to keep in mind

Nothing rigid here — just some patterns that tend to keep things looking consistent across integrations:

- Ink and Canvas are the primary button colors, and they're a good starting point even if you tweak things for your app
- The wordmark SVG already contains the word "Discovr", so there's no need to add it as text alongside the logo
- When the button has a dark (Ink) fill, use the light-fill wordmark (`Discovr_dark.svg`), and vice versa — they're designed to sit on opposite surfaces
- The logo looks best at its natural aspect ratio — scaling by height works well, but stretching or cropping tends to look off
- This button is really only meant to trigger the Discovr sign-in flow, so try to keep it for that use case specifically

## Button examples

The wordmark SVG already contains the word "Discovr", so in buttons the pattern is `Sign in with ` + the wordmark SVG inline — the logo _is_ the label. You don't need to add the word "Discovr" as text alongside it.

| Button style                           | Best for                                 |
| -------------------------------------- | ---------------------------------------- |
| Pill (Sign in with :Discovr)           | Hero sections, dedicated sign-in screens |
| Solid compact (Continue with :Discovr) | Secondary options, login pages           |
| Outlined (:Discovr Sign In)            | Side-by-side with other sign-in methods  |
| Logo only (full-width)                 | Dedicated Discovr sign-in pages          |

```tsx React
import { useState } from "react";

const LOGO = {
	light: "https://docs.discovr.media/assets/Discovr.svg",
	dark: "https://docs.discovr.media/assets/Discovr_dark.svg",
};

export function SignInPill({ onSignIn }: { onSignIn: () => Promise<void> }) {
	const [loading, setLoading] = useState(false);
	const dark = window.matchMedia("(prefers-color-scheme: dark)").matches;

	return (
		<button
			onClick={async () => {
				setLoading(true);
				try {
					await onSignIn();
				} finally {
					setLoading(false);
				}
			}}
			disabled={loading}
			style={{
				display: "inline-flex",
				alignItems: "center",
				gap: 8,
				height: 36,
				padding: "0 20px",
				border: "none",
				borderRadius: 100,
				background: dark ? "#EAEAEA" : "#1A1A1A",
				color: dark ? "#2F2F2F" : "#F4F1EA",
				fontFamily: '"DM Sans", "Inter", system-ui, sans-serif',
				fontSize: 14,
				fontWeight: 500,
				whiteSpace: "nowrap",
				opacity: loading ? 0.5 : 1,
				cursor: loading ? "default" : "pointer",
				transition: "opacity 150ms ease",
			}}
		>
			{loading ? (
				"Signing in…"
			) : (
				<>
					<span>Sign in with</span>
					<img src={dark ? LOGO.dark : LOGO.light} alt="Discovr" style={{ height: 13 }} />
				</>
			)}
		</button>
	);
}
```

```tsx React
};

export function GetStarted({ onSignIn }: { onSignIn: () => Promise<void> }) {
	const [loading, setLoading] = useState(false);
	const dark = window.matchMedia("(prefers-color-scheme: dark)").matches;

	return (
		<button
			onClick={async () => {
				setLoading(true);
				try {
					await onSignIn();
				} finally {
					setLoading(false);
				}
			}}
			disabled={loading}
			aria-label="Get started with Discovr"
			style={{
				display: "flex",
				alignItems: "center",
				justifyContent: "center",
				width: "100%",
				height: 40,
				border: "none",
				borderRadius: 8,
				background: dark ? "#EAEAEA" : "#1A1A1A",
				opacity: loading ? 0.5 : 1,
				cursor: loading ? "default" : "pointer",
				transition: "opacity 150ms ease",
			}}
		>
			{loading ? (
				<span
					style={{
						color: dark ? "#2F2F2F" : "#F4F1EA",
						fontFamily: '"DM Sans", "Inter", system-ui, sans-serif',
						fontSize: 14,
						fontWeight: 500,
					}}
				>
					Signing in…
				</span>
			) : (
				<img
					src={dark ? LOGO.dark : LOGO.light}
					alt="Get started with Discovr"
					style={{ height: 14 }}
				/>
			)}
		</button>
	);
}
```
