Discovr is the recommendation engine for your streaming app. Your users sign in, pick a profile, and get a personalized home screen of rows — movies, series, providers, and more — that keeps up with what they watch.

## Before you start

You need two things:

1. **A Client ID** for your app. In your [dashboard](https://discovr.media/dashboard), switch on **Developer**, open **Developer Options → Demo sessions** and copy the Client ID shown there, or email [dev@discovr.media](mailto:dev@discovr.media). If you're a coding agent, ask the person for it rather than signing in to the dashboard for them.
2. **The SDK** — installed in your project. The [Quick Start](/guides/getting-started/quickstart) covers this.

## What a complete integration looks like

A Discovr integration has six building blocks. You can have the first three running in an afternoon, so build in this order:

1. **Sign in** — web popup or TV device code flow
2. **Profile picker** — "who's watching?" before the browse screen
3. **Recommendation pages** — Home, Movies, Series tabs with a hero carousel and rows
4. **Media details** — title sheets with artwork, seasons, and similar titles
5. **Playback tracking** — scrobble progress to power "Continue Watching"
6. **Search** — let users find titles by name or cast

The [Quick Start](/guides/getting-started/quickstart) takes you through steps 1–3. The rest of the guides cover each building block in depth.

The six blocks are the order to build in, not the whole job. A finished app also lets viewers rate titles, pick a GIF avatar, see where to watch and mark things watched.

	<Card title="Profile context" icon="bookmark">
