title: "Finished episodes with getSeasonState"
description: "Find out which episodes of a TV season the viewer has finished, to put a checkmark on each one and to power season pickers."
---

You've got the title-level picture from [`getTitleState()`](/guides/profile-context/media-profile-meta) — whether the show as a whole is complete, and which seasons are done. When the viewer drills into a specific season, you can fetch a clean per-episode breakdown for that season with **`getSeasonState()`**.

Call `getSeasonState()` for one season of a `TV_…` title, and get back whether each episode is finished, plus the season's own aggregate `completed` flag.

<Note>
	This needs an active profile — start with
	[**`selectProfile()`**](/sdk-reference/authentication/select-profile), covered in
	[Profiles](/guides/profiles). Code samples use **TypeScript / Kotlin / Swift**.
</Note>

## Pair it with getSeasonDetails

`getSeasonState()` only says what's finished — no episode titles, stills, or air dates. Pair it with [`getSeasonDetails()`](/sdk-reference/media/get-season-details) to build a season view:

| Data you need                          | API to call                                                         |
| -------------------------------------- | ------------------------------------------------------------------- |
| Episode titles, stills, air dates      | [`getSeasonDetails()`](/sdk-reference/media/get-season-details)     |
| Which episodes are finished            | [`getSeasonState()`](/sdk-reference/profile-lists/get-season-state) |
| Whole-title state (rating, watchlist…) | [`getTitleState()`](/guides/profile-context/media-profile-meta)     |

A typical season screen fetches `getSeasonDetails()` first to render the episode list right away, then layers `getSeasonState()` on top for the checkmarks. Both need an active profile, so they can run in parallel.

## What you get back

The same shape on every platform — shown here with TypeScript types:

```typescript
interface SeasonState {
	season: number;
	completed: boolean; // Whether every aired episode of this season is watched
	episodes: {
		episode: number;
		completed: boolean;
	}[];
}
```

`completed` at the season level uses the same rule described in [Completion rules](/guides/profile-context/media-profile-meta#completion-rules): every aired episode in the season has to be watched (≥ 80% progress or marked watched) for the season itself to count as complete.

Each entry in `episodes` tells you whether that episode is finished, which is enough for a checkmark per episode.

It doesn't report how far through a half-watched episode the viewer got, so there's no per-episode progress bar to draw here. The place in the episode they're watching right now is `playback` on [`getTitleState()`](/guides/profile-context/media-profile-meta), and Continue Watching has it too.

## Example: a checkmark per finished episode

Fetch episodes and finished state in parallel, then merge them by episode number:

{/* sample: profile-context-season-profile-meta-example-finished-episodes */}

<CodeGroup>

```typescript TypeScript
import { DiscovrClient } from "discovr";
import type { SeasonDetailsResponse, SeasonState } from "discovr";

const client = new DiscovrClient("your-client-id");

async function loadSeasonWithFinished(tvId: string, seasonNumber: number) {
	const [details, state]: [SeasonDetailsResponse, SeasonState] = await Promise.all([
		client.getSeasonDetails(tvId, seasonNumber, { language: "en" }),
		client.getSeasonState(tvId, seasonNumber),
	]);

	const finishedByEpisode = new Map(state.episodes.map((e) => [e.episode, e.completed]));

	return (details.episodes ?? []).map((episode) => ({
		...episode,
		finished: finishedByEpisode.get(episode.episodeNumber) ?? false,
	}));
}
```

```kotlin Kotlin
import api.discovr.DiscovrClient
import api.discovr.models.SeasonDetailsResponse
import api.discovr.models.SeasonState

suspend fun loadSeasonWithFinished(
	client: DiscovrClient,
	tvId: String,
	seasonNumber: Int
): Pair<SeasonDetailsResponse, SeasonState> {
	val details = client.getSeasonDetails(mediaId = tvId, seasonNumber = seasonNumber, language = "en")
	val state = client.getSeasonState(mediaId = tvId, seasonNumber = seasonNumber)
	return details to state
}
```

```swift Swift
import Discovr

func loadSeasonWithFinished(
	client: DiscovrClient,
	tvId: String,
	seasonNumber: Int
) async throws -> (SeasonDetailsResponse, SeasonState) {
	async let details = client.getSeasonDetails(mediaId: tvId, seasonNumber: seasonNumber, language: "en")
	async let state = client.getSeasonState(mediaId: tvId, seasonNumber: seasonNumber)
	return try await (details, state)
}
```

</CodeGroup>

<Tip>
	Only fetch `getSeasonState()` for the season the viewer has open. Don't call it once per season to
	build a season picker — `getTitleState().completedSeasons` already gives you completed seasons at
	the title level in a single request.
</Tip>
